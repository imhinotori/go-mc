<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| region A goroutine ↔ region B goroutine | Two regions tick concurrently; NEITHER may touch the other's store during the fan-out. The barrier (wg.Wait) is the only synchronization point where cross-region reads (tracker, transfer) are legal. |
| region tick ↔ global player list | A region reads t.players (broadcast/tracker) while the coordinator holds registrations stable (drained pre-fan-out) — read-only crossing. |
| off-tick async worker ↔ owning region | pathReady/spawnCandidatesReady re-resolve the owning region by id on the coordinator at the barrier; a result for a transferred/despawned entity is dropped. |
| frozen plugin registry ↔ N region goroutines | The frozen *host.Manager hooks are read from every region thread — lock-free by the Phase-21 freeze guarantee; only the HANDLES resolve per-region. |

The Docker -race gate (Task 4) is the enforcement; TestRegionizedTickRace exercises it. |
