# 774 → 776 Generated-Data Diff Enumeration (GEN-04)

**Audit artifact.** This file enumerates the protocol-774 → protocol-776 (Minecraft 1.21.11 → 26.2)
byte-layout delta by mechanically diffing the Plan-01 774 baseline against the Plan-02 regenerated
trees. **The diff IS the enumeration** — every delta below is backed by a line in the actual
`diff` output between the two trees, never asserted from memory (the explicit defense against
Pitfall 2 for a version that post-dates the wiki and training data).

- **Before (774):** `.planning/phases/01-foundation-fork-codegen/baseline-774/{data,level}/` (Plan 01 snapshot)
- **After (776):** `data/*` + `level/*` (Plan 02 codegen output from the sha1-verified 26.2 jar `823e2250d24b3ddac457a60c92a6a941943fcd6a`)
- **Diff method:** `diff -ruN baseline-774/<tree> <tree>` per generated package; set-deltas via
  `comm` on the extracted identifier sets (ID-shift-immune, so insertions don't masquerade as churn).

Every generated file's header line flips from `... from 1.21.11/<report>.json` to
`... from 26.2/<report>.json` — confirming the entire tree was regenerated from the 26.2 jar,
not hand-edited (e.g. `data/packetid/packetid.go`, `data/registryid/fluid.go`, `data/entity/entity.go`).

### 1. Packet-ID table — `data/packetid/packetid.go` (+5 packets, header retargeted)

- Header line: `from 1.21.11/packets.json` → `from 26.2/packets.json`.
- Set-delta (via `comm` on the const-name set, 254 → 259):
  - **ADDED (5):** `ClientboundGameRuleValues`, `ClientboundLowDiskSpaceWarning`,
    `ServerboundAttack`, `ServerboundSetGameRule`, `ServerboundSpectatorAction`.
  - **REMOVED:** none.
- The iota-based const blocks reindex every subsequent ID, so the raw line diff is large; the
  *semantic* delta is the +5 names above plus the full reshuffle of numeric assignments.
- **Trace:** appears in `diff baseline-774/data/packetid/packetid.go data/packetid/packetid.go`.
  Stringer tables `clientboundpacketid_string.go` / `serverboundpacketid_string.go` also differ
