THE ORE BODY (net.minecraft.world.level.levelgen.feature.OreFeature.place → doPlace, javap -c) — port jar-exact:
```
place: read size; f = rng.nextFloat() * PI;  // angle (1 draw)
  compute the line endpoints (x0,y0,z0)-(x1,y1,z1) from sin/cos*size/8 ± offsets (the jar's exact float math, several nextDouble/nextFloat draws — transcribe);
  doPlace: for i in 0..size: interpolate center; rr = the per-step radius from rng (a draw); fill the ellipsoid (xx,yy,zz) within rr;
  for each candidate (x,y,z): existing = view.GetBlock; for each target: if target.rule_test(existing, rng) { if discardOnAir>0 && air-adjacent && rng.nextFloat()<discard skip; view.SetBlock(x,y,z, target.state); break } }
```
The EXACT draw sequence (angle, the endpoint doubles, per-step radius, the per-position discard float) IS the determinism contract — transcribe javap -c, do NOT approximate. air-adjacent = any of the 6 neighbors is air (via view.GetBlock).

THE RANDOM_PATCH BODY (net.minecraft.world.level.levelgen.feature.RandomPatchFeature.place, javap -c) — RandomPatchConfiguration{tries, xz_spread, y_spread, feature (an inner Holder<PlacedFeature>)}:
```
for i in 0..tries:
  ox = pos.X + rng.nextInt(xz_spread*2+1) - xz_spread
  oz = pos.Z + rng.nextInt(xz_spread*2+1) - xz_spread     // CONFIRM jar order: x then z, then y (transcribe)
  oy = pos.Y + rng.nextInt(y_spread*2+1) - y_spread
  place the inner PlacedFeature at (ox,oy,oz); if it placed, count++
return count > 0
```
The inner feature is a PlacedFeature — to place it, resolve it through the registry (it is usually a simple_block whose body is in THIS plan). Reuse the bound-placed-feature path: the inner feature's OWN placement modifiers re-apply (this is the same recursion 12-03 generalizes for selectors). For random_patch the inner placement is typically empty ([]), so a direct body call at (ox,oy,oz) suffices — but route through the shared sub-feature placement helper 12-03 builds IF it lands first; else a direct inner-body call is acceptable for random_patch (document the choice + that 12-03 unifies it). Since 26.2 has ZERO top-level random_patch, the test uses a synthetic/constructed config.
