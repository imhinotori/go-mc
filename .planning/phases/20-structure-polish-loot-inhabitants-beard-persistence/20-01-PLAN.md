<objective>
Build the shared loot evaluator as a standalone PURE package `level/loot` — the keystone STRUCT-POLISH-01 deliverable. It parses the embedded vanilla loot-table JSON into a Go model, ports the LootTable/LootPool roll engine with the EXACT vanilla RNG draw order, and exposes one entry point `Roll(table, seed, ctx) []ItemStack` that BOTH block drops (20-02) and chest fill (20-02) call. This plan ships the package + the mandatory golden seed-reproduction test; it touches NO server/world code.

Purpose: per-seed-reproducible vanilla loot. The 5 target chest groups (desert/jungle temple, igloo, mineshaft, dungeon, village) use a tiny, bounded element set (3 functions, 1 number-provider + implicit constant, 2 entry types, NO per-entry conditions). The block-table delta (alternatives, match_tool, survives_explosion, apply_bonus, explosion_decay) is SHAPED for here but PORTED in 20-02 for the GAMEPLAY-06 faithful path. Do NOT port all ~50 loot functions — only the enumerated MUST-PORT set.

Output: a pure `level/loot` package importable by both `server` and `world/structure` with no import cycle, plus the golden test that proves vanilla reproduction.
</objective>
