<objective>
Port the FULL density-function NODE-TYPE set + the Tier-D router/settings loader — the LOGIC that evaluates the WHOLE DATA graph from Wave 1, seeded by the Tier-A/B primitives from Wave 2. **This is the plan where caves become "free."** Because the wired graph is DATA and the evaluator is data-driven, the cave density functions (`entrances`/`noodle`/`pillars`/`spaghetti_2d`) are just MORE NODES in the SAME graph producing the SAME `final_density` — caves are NEGATIVE-density regions the noise graph itself carves, NOT a separate system. So the ONLY incremental cost over a T0 surface subset is porting the FULL ~30 node-type set (not just the surface nodes) so the whole `overworld.json` graph parses + evaluates. Once it does, hills AND caves are both produced by `final_density`.

**The complete node-type set (verified from the jar this session** by walking `overworld.json` + all 35 `density_function/**.json` incl. the caves subtree): `constant, y_clamped_gradient, noise, shifted_noise, shift_a, shift_b, add, mul, min, max, abs, square, cube, half_negative, quarter_negative, clamp, squeeze, range_choice, interval_select, spline, old_blended_noise, interpolated, flat_cache, cache_2d, cache_once, cache_all_in_cell, blend_alpha, blend_offset, blend_density, weird_scaled_sampler, beardifier`. `weird_scaled_sampler` is what the spaghetti/noodle cave functions use; `beardifier` returns 0 (no structures). `end_islands` is the ONLY density node DEFERRED (End-only, never referenced by the overworld graph). A node type outside the supported set ERRORS LOUDLY at parse — never a silent mis-evaluation.

This plan delivers THREE things: (1) `world/levelgen/density/` — the `Function` interface + the FULL ported node types + the `parse(json,registry)→Function` builder; (2) `world/levelgen/router.go` — `NoiseGeneratorSettings` + `NoiseRouter` (ALL the named router functions, because the Aquifer in Wave 5 needs `barrier`/`fluid_level_floodedness`/`fluid_level_spread`/`lava` and the OreVeinifier needs `vein_toggle`/`vein_ridged`/`vein_gap`) + `RandomState`, the bridge from Tier-A seeding to the graph; (3) the visitor/`mapAll` that binds the parsed noise nodes to their seeded noises and preserves interpolation markers.

The DATA/LOGIC split is honored end-to-end for the WHOLE graph: `NewRouter(seed)` parses the full wired graph (DATA — incl. the cave branches) and binds it to seeded primitives (Tier A/B). Determinism holds (Pitfall 7). The `interpolated` marker is preserved (NOT a no-op — Pitfall 3). ZERO new dependencies.

Purpose: PARITY-01's terrain SHAPE — hills, valleys, oceans, AND caves/ravines-via-noise — is `final_density`; the Aquifer + OreVeinifier (Wave 5) consume the `fluid_level_*`/`lava`/`vein_*` router functions. Without the FULL ported node set + the bound graph there is nothing to sample, and caves would be silently missing.
Output: world/levelgen/density/{df,nodes,spline,parse}.go (+ test), world/levelgen/router.go (+ test). ZERO new dependencies.
</objective>
