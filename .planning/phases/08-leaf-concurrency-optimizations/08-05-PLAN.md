<objective>
OPT-03: move the natural-spawn candidate SCAN off-tick while keeping the spawn MUTATION on the owner. Today `naturalSpawn` (spawner.go) scans eligible columns + `findStandableY` (reading the live ChunkManager) AND calls `entityStore.add` all synchronously on the tick. This plan splits it: ON the tick, build an immutable snapshot of the eligible loaded columns near players PLUS the world-solidity those columns need (copied like `snapshotRegion` copies path solidity), then SUBMIT the standable-Y scan to the Wave-0 `spawnPool`. The scan computes candidate `(x,y,z)` positions over ONLY the snapshot and rejoins as `spawnCandidatesReady{candidates}` via the UNCHANGED `applyAsyncResults` seam. `spawnCandidatesReady.applyTo` then RE-CHECKS the CREATURE cap on the authoritative store and adds ONE Pig via `entityStore.add` + `idAlloc.AllocID` — all on the owner.

The load-bearing safety (08-RESEARCH Seam Map OPT-03 + Pitfall 3): the off-tick scan's mob count is a SNAPSHOT, so the owner re-validates the anti-flood cap before mutating — a candidate that is now over-cap or whose position is now occupied (`mobNear`) is DROPPED. The scan is advisory; the owner is authoritative. Every existing DoS guard (the `spawnInterval` throttle, the CREATURE cap, the `mobNear` packing guard, the bounded `findStandableY` window) survives the swap.

This plan touches `tick.go`/`async.go` (the spawnCandidatesReady contract) and `spawner.go`, overlapping the OPT-01/02 plans' shared files, so it runs in Wave 3 (after OPT-02). It depends on the 08-01 substrate (spawnPool, asyncIn2, the spawnCandidatesReady contract).

Purpose: OPT-03 ("async mob spawning scans candidate locations off-thread") + its slice of OPT-06 (this subsystem -race clean). The column/standable-Y scan is the spawner's per-cycle cost; moving it off-tick is the Leaf spawn optimization, with the mutation safely rejoined.
Output: spawner.go (the split scan + submit), async.go (spawnCandidatesReady.applyTo filled), the tests. New external deps: none (ants landed in 08-01).
</objective>
