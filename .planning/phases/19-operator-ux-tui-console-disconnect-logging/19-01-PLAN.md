<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| server goroutine → log bridge | tick/net/keepalive goroutines emit slog records crossing into the TUI forwarder; untrusted player names/addrs ride attrs into the rendered viewport |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-19-01 | Tampering | formatLine (handler.go) rendering attacker-controlled name/addr | mitigate | sanitize() strips ASCII control bytes (\x00-\x1f,\x7f) from every attr value + msg before it reaches the viewport — terminal/ANSI-injection neutralized (research Security row 1) |
| T-19-02 | Denial of Service | the log→TUI bridge under a log flood | mitigate | bounded chan (cap 1024) + non-blocking send + drop-on-full + single forwarder; the emitting tick/net goroutine NEVER blocks on a slow render (research Pitfall 1) |
| T-19-03 | Denial of Service | unbounded memory from a slow render | accept→mitigate | the bounded+drop channel caps memory; dropped lines are best-effort console output (the always-on stderr path keeps the full record) |
</threat_model>
