|----------|-------------|
| client -> handleAttack (ServerboundAttack) | The packet carries only a target entity id; the server resolves the victim and computes the amount. Untrusted input crosses here. |
| attacker region goroutine -> victim region store | A cross-region hit must NOT mutate the victim's store mid-tick; it crosses via the barrier-queue. |
| Starlark goal -> *Entity damage state | The goal reads frozen scalars via a region-bound handle, never a live source. |
