<objective>
Persist computed StructureStarts to region NBT (STRUCT-POLISH-04) so starts survive a reload without recompute. Port `StructureStart.createTag` / `loadStaticStart` (the flat `{id, ChunkX, ChunkZ, references, Children}` compound), give every Sulfur piece type a `Save()/Load()` NBT method (the bulk of the work — the `Children` list), and wire the two-way cache<->region seam: WRITE the cache's `[]*StructureStart` into the chunk's `structures.Starts` compound on save; READ them back on load INSTEAD of recomputing — with a recompute fallback because starts are PURE over (seed,pos).

Purpose: a true optimization (Pitfall 4 / Assumption A6 — recompute is always a valid fallback). Persistence also enables the reload-safe one-shot spawn guard 20-04 relies on (a reloaded structure chunk is a region hit that bypasses PostProcess, so spawns don't re-run — but persisting the start NBT makes the guard robust if recompute ever re-places). This plan owns the piece-NBT + the region seam; it does NOT touch piece.go (20-02 owns that) or the generator ordering (20-05).

Output: StructureStarts round-trip NBT; the cache loads from region when present; recompute remains the coherence authority.
</objective>
