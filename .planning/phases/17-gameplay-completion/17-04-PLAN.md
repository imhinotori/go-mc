<objective>
GAMEPLAY-06: spawn pickable item drops on block break. `handlePlayerAction` sets the broken block to air, acks, and broadcasts BlockUpdate — then returns without ever spawning a drop. After a successful break, look up the block's drop, spawn an `entity.Item` (ID 71) at the block center, populate its ITEM metadata so it renders, and add it to the store so GAMEPLAY-01's tracker broadcasts AddEntity.

Purpose: Broken blocks drop nothing — there is no Item entity, no metadata, no broadcast. This depends on 17-01 (the keystone) because the drop's visibility rides the entity-tracker broadcast path 17-01 unblocks.
Output: Breaking a block spawns a visible, tracked Item entity carrying the dropped stack.

DEPENDS ON 17-01: the entity store + tracker broadcast player/entity path must be live (17-01) for the dropped Item to render on clients. Touches block_interact.go + entity_encode.go + new block_drop.go — disjoint from 17-02 (fluid) and 17-03 (damage) files, so it runs parallel with them in Wave 2.
</objective>
