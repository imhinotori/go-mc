<objective>
Port Tier-E `NoiseChunk` — the cell-sample + trilinear-interpolation core — that turns the bound `final_density` graph (Wave 3, INCLUDING the cave branches) into a per-block density field. This is the load-bearing performance + parity pattern (09-RESEARCH Pattern 2): do NOT evaluate `final_density` for all 16×384×16 = 98K blocks per chunk — vanilla samples on a coarse grid (`size_horizontal:1` → 4-block cells, `size_vertical:2` → 8-block cells → ~768 corner samples/chunk) and TRILINEARLY interpolates between the 8 cell corners. This is not just an optimization — the smooth cell-lerp is part of vanilla's terrain CHARACTER, so matching it is a parity requirement (per-block evaluation is a performance cliff off-tick AND subtly non-vanilla — Pitfall 5).

**Caves come through this loop for free:** because `final_density` (Wave 3) carries the cave branches (entrances/noodle/pillars/spaghetti), the SAME cell sample + trilerp produces hills (positive density) AND caves (negative density underground) — there is no separate cave pass in NoiseChunk. This plan focuses on the CELL MACHINERY (the sample loop + the interpolator + a per-block density accessor); the real fluid/ore placement (Aquifer + OreVeinifier) is Wave 5, which consumes this density field.

This plan delivers: (1) `world/levelgen/noisechunk.go` — `NewNoiseChunk(router, pos)` + the coarse-grid cell sample of `final_density` + a per-block `finalDensity(x,y,z)` accessor (the trilerped value) + a PROVISIONAL fill helper (`density>0`→stone, else `y<sea_level`→water, else air; bedrock floor) so the machinery is testable end-to-end; (2) `world/levelgen/interpolator.go` — the ported `NoiseInterpolator` (per-cell corner buffers + the trilerp in vanilla's cell-fill order) that NoiseChunk drives for the `interpolated` markers (Pitfall 3).

The provisional sea-level water rule is a PLACEHOLDER for testing the cell loop — Wave 5's Aquifer REPLACES it with the real water/lava-table placement in carved regions. ZERO new dependencies, ZERO concurrency (the existing off-tick worker drives Generate; this is pure sampling).

Purpose: NoiseChunk is the bridge from the bound graph to placeable blocks — the cell interpolation is the parity+perf hinge (Pattern 2), and it is where caves materialize (negative density). Wave 5 (Aquifer/OreVein), Wave 6 (carvers), Wave 7 (surface/biome), and Wave 8 (the assembled Generator) all sit on this density field.
Output: world/levelgen/noisechunk.go, world/levelgen/interpolator.go (+ test). ZERO new dependencies.
</objective>
