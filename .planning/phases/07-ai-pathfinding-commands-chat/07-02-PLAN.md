<objective>
Port vanilla A* navigation (AI-02) as the EXACT request->snapshot->result seam vanilla itself uses — the load-bearing Phase-8 hinge. The decisive discovery (07-RESEARCH): vanilla's `PathFinder.findPath` reads a `PathNavigationRegion` — a COPIED `ChunkAccess[][]` snapshot — never the live world. Porting that shape makes async pathfinding (Phase 8 / OPT-01) a swap of the EXECUTOR, not a rewrite. This plan structures it so `computePath(req pathRequest) *Path` is a PURE function of an immutable snapshot (no `*TickLoop`, no live `entityStore`/`ChunkManager` pointer); Phase 7 runs it INLINE on the tick; Phase 8 hands the same `pathRequest` to an `ants` pool and the `Path` rejoins via the EXISTING `applyAsyncResults` seam with ZERO logic change.

Four ported files (idiomatic-Go from the javap-read sources, the STANDING MANDATE — never a GPL paste): (1) `server/path_region.go` — `PathNavigationRegion` as an immutable `pathRegion` (a copied block-solidity snapshot of the bounding box around mob->target, built on the tick from `world.ChunkManager.GetBlock`); (2) `server/pathfinder.go` — `PathFinder.findPath` (A* over the snapshot: a binary-heap open set, g = `node.distanceTo`, h = `getBestH` min-distance-to-any-target, `reconstructPath`, and a `maxVisitedNodes` BUDGET so an unreachable target cannot blow the MSPT budget — Pitfall 6); (3) `server/node_evaluator.go` — `WalkNodeEvaluator` (the 8 neighbor moves + step-up/down, `getPathType` WALKABLE/BLOCKED/OPEN, corner-cut rejection) reading the SNAPSHOT solidity; (4) `server/navigation.go` — `GroundPathNavigation` (`requestPath` = snapshot+computePath; `tick` = advance the path node toward the next waypoint and feed a desired Δ to the EXISTING `moveEntity`, which resolves collision/landing/re-bucket; the UNCHANGED `entityTracker` auto-broadcasts the moved mob — NO new entity encoder).

`navigation.tick` is wired into the per-mob `serverAiStep` driver (`server/ai_mob.go`, after the 07-01 goal arbitration) so a stroll goal's `wantTarget` becomes an A* path the mob WALKS. Everything is SYNCHRONOUS on the tick goroutine (TICK-05), executed INLINE. ZERO new dependencies (the seam is async-READY but inline; NO ants/conc — Phase 8).

Purpose: AI-02 "synchronous A* navigation moves mobs around the world, built as request->snapshot->result executed inline (seam ready for async)" — the snapshot purity is the single discipline that makes OPT-01 a free swap. A mob that paths around an obstacle is the interactive proof (07-06).
Output: server/path_region.go, server/pathfinder.go, server/node_evaluator.go, server/navigation.go, the serverAiStep wiring in server/ai_mob.go, and the tests. ZERO new dependencies.
