<objective>
OPT-05: add the `.linear` region file format (whole-region zstd) to reduce disk I/O and footprint, EXTENDING `save/region` in-place alongside the unchanged `.mca` Anvil codec. The `.linear` format packs an entire 32×32 region into ONE zstd-compressed file (vs `.mca`'s per-chunk zlib sectors with 4KB padding), giving ~50% disk savings on populated regions. This plan implements the exact binary layout (signature `0xc3ff13183cca9d9a`, header `>QBQbhIQ`, 1024 `>II` chunk headers + concatenated NBT body, all zstd-compressed, trailing signature), wired behind the EXISTING off-tick `world.Worker.loadOrGenerate` call site as an OPT-IN codec: the loader PREFERS `.linear`, falls back to `.mca`, else generates — so vanilla `.mca` worlds stay readable and `.linear` is only written when configured.

This is the one Phase-8 plan that is NOT an executor swap — it changes the on-disk BYTES, not the threading. Region IO is already off-tick (Phase 4's `world.Worker` runs `loadOrGenerate` in a short-lived goroutine, results rejoin via `chunkReady`), so `.linear` rides that proven off-tick path and adds no new tick-boundary crossing. It is file-disjoint from the OPT-01 pathfinding swap (different packages), so it runs in the same wave. Compression is pure-Go `klauspost/compress/zstd` — the ONE new external dep Phase 8 adds beyond the 08-01 ants/xsync stack — to keep the `CGO_ENABLED=0` static binary.

Purpose: OPT-05 ("linear region file format reduces disk I/O and footprint") + its slice of OPT-06 (the codec round-trip is unit-tested; the off-tick worker stays -race clean). Demonstrable via the round-trip test + a size comparison vs the .mca equivalent.
Output: save/region/linear.go (the codec + the bomb guard), world/worker.go (format-aware loadOrGenerate), the tests, klauspost/compress in go.mod.
</objective>

File = [leading signature uint64 BE] [header `>QBQbhIQ`: magic(8) version(1) newestTimestamp(8) compressionLevel(1) chunkCount(2) completeRegionLength(4) hash/reserved(8)] [zstd body] [trailing signature uint64 BE].
