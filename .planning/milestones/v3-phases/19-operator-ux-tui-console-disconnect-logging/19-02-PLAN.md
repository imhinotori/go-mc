<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| TUI goroutine → tick goroutine | a console-typed line crosses onto the tick where command handlers mutate authoritative state |
| local operator → command graph | the console is an implicit operator; its input runs privileged command nodes |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-19-04 | Tampering (race) | console command mutating tick-owned state off-thread | mitigate | EnqueueConsoleCommand hands the line to the tick via consoleCmd; runConsoleCommand → executeCommand runs on the tick goroutine in drainRegistrations (research Pitfall 7 / TICK-05) |
| T-19-05 | Denial of Service | unbounded console input | mitigate | runConsoleCommand reuses maxCommandLen (256) bound BEFORE Execute (research Security V5); EnqueueConsoleCommand is bounded + drop-on-full |
| T-19-06 | Elevation of Privilege | console grants all command nodes | accept | the console IS the operator (local stdin); the permissionResolver gate stays the structural hook for a future ops model (research Security V4; Deferred: full ops-list model) |
</threat_model>
