- The overworld **biome climate parameters** baked into `OverworldBiomes.class` (32KB) — extracted via a small Java extractor for the multi-noise biome source (Wave 7, now IN SCOPE for full parity).

This plan delivers: (1) `tools/extract_worldgen.go` — a NEW offline step pure-unzipping the FULL worldgen JSON trees (no Java) + invoking (2); (2) `tools/GenBiomeParams.java` — the ONE Java extractor (the baked biome params); (3) `world/levelgen/data/embed.go` — the `//go:embed` + typed accessors the later waves consume.

Purpose: PARITY-01's whole terrain shape (hills + CAVES + ravines + aquifers + ore veins + biome-varied surfaces) comes from the real graph + the carver/aquifer/ore systems fed by it; without the extracted+embedded data the later waves have nothing to evaluate. The DATA-DRIVEN decision is the load-bearing architecture choice.
Output: tools/extract_worldgen.go, tools/GenBiomeParams.java, world/levelgen/data/embed.go (+test), and the extracted JSON tree under world/levelgen/data/. ZERO new runtime dependencies (stdlib embed + encoding/json only).
